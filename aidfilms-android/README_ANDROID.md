# AidFilms Android App

Цей застосунок дозволяє спільно переглядати відео (m3u8, HLS, mp4) з синхронізацією через Firebase Realtime Database.

## Функції
- **Темна тема**: Весь інтерфейс виконаний у темних тонах.
- **Синхронізація**: Відтворення (плей/пауза) та позиція відео синхронізуються між усіма учасниками в одній кімнаті.
- **Підтримка потоків**: ExoPlayer підтримує m3u8, HLS та mp4.
- **Повноекранний режим**: Плеєр автоматично займає весь доступний простір.

## Налаштування
1. Створіть проект у [Firebase Console](https://console.firebase.google.com/).
2. Додайте Android-застосунок з пакетним ім'ям `com.example.aidfilms`.
3. Завантажте файл `google-services.json` і помістіть його в папку `app/`.
4. Увімкніть Realtime Database у вашому проекті Firebase.

## Збірка
Для збірки APK виконайте:
```bash
./gradlew assembleDebug
```
Результат буде в `app/build/outputs/apk/debug/`.
